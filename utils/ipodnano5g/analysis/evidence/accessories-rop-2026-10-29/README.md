# `accessories.reg`-Rehost-Belege (29.10.2026)

Diese Ablage enthält read-only Ghidra-Exporte und ARM1176-QEMU-Rehosts für den OSOS-Stream-/FAT-Lesepfad von `accessories.reg`. Kein QEMU-Test greift auf den iPod zu.
